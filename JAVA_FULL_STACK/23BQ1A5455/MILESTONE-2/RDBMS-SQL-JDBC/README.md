# 📌 Repository Overview

This repository contains all the practical exercises, module implementations, and the final mini project completed as part of the **Wipro TalentNext Java Full Stack Learning Program** under the **RDBMS, SQL & JDBC** module.

The repository demonstrates the complete learning journey from establishing a database connection to developing a fully functional JDBC-based User Management System using Oracle Database.

---

# 🎯 Learning Objectives

- Understand Relational Database Management Systems (RDBMS)
- Learn SQL fundamentals and database operations
- Establish JDBC connectivity with Oracle Database
- Execute SQL queries from Java applications
- Process query results using ResultSet
- Perform CRUD operations using PreparedStatement
- Work with Metadata Objects
- Execute Stored Procedures using CallableStatement
- Manage Database Transactions
- Build a real-world JDBC application using the DAO Design Pattern
